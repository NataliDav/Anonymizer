# Local Table Anonymizer

**Локальный анонимизатор таблиц** — Python-утилита для замены персональных данных (ФИО, адрес, телефон и т.д.) в электронных таблицах на обезличенные индексы с возможностью обратного восстановления по зашифрованному файлу-ключу.

> **100% офлайн.** Никаких сетевых запросов, никаких нейросетей. Все данные остаются на вашем компьютере.

---

## Key Features

- **Анонимизация** — замена ПДн на стабильные индексы (`FIO_0001`, `ADR_0001`, `TEL_0001`)
- **Обратимость** — полное восстановление исходных данных по файлу-ключу
- **Два интерфейса** — GUI (Tkinter) и CLI
- **Шифрование** — файл-ключ защищён AES-128-CBC + HMAC-SHA256 (Fernet), ключ выводится из пароля через PBKDF2 (600k итераций)
- **Форматы** — чтение/запись `.xlsx` и `.csv` (UTF-8, cp1251)
- **Интегрити-контроль** — HMAC-отпечаток при восстановлении для обнаружения подмены

## Requirements

- Python 3.12+
- `cryptography` (для шифрования файла-ключа)
- `openpyxl` (для работы с .xlsx)

## Installation

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/local-table-anonymizer.git
cd local-table-anonymizer

# Установить зависимости
pip install -r anonymizer/requirements.txt
pip install cryptography
```

## Usage

### GUI Mode (по умолчанию)

```bash
python anonymizer.py
```

Откроется окно с двумя вкладками: **Анонимизация** и **Восстановление**.

### CLI Mode

#### Анонимизация

```bash
python anonymizer.py encode Data_unput.xlsx --cols "ФИО,Адрес,Телефон"
```

**Опции:**

| Флаг | Описание |
|------|----------|
| `--cols` | Столбцы ПДн через запятую (обязательный) |
| `--prefixes` | Префиксы: `"ФИО=FIO_,Адрес=ADR_"` |
| `--out` | Путь анонимной таблицы (по умолчанию `*_anon.*`) |
| `--key` | Путь файла-ключа (по умолчанию `*_KEY.kvault`) |
| `--password` | Пароль (иначе запросит скрыто) |

#### Восстановление

```bash
python anonymizer.py decode Data_unput_anon.xlsx --key Data_unput_KEY.kvault
```

**Опции:**

| Флаг | Описание |
|------|----------|
| `--key` | Файл-ключ `.kvault` (обязательный) |
| `--out` | Путь восстановленной таблицы |
| `--password` | Пароль |

## How It Works

### Анонимизация

1. Для каждого выбранного столбца генерируется случайная **соль** (16 байт)
2. Каждое значение нормализуется (`strip + lower + NBSP→пробел`) и хешируется через **HMAC-SHA256**
3. Одинаковые значения получают один индекс (порядок — по первому появлению)
4. Маппинг `индекс ↔ значение` сохраняется в зашифрованный `.kvault` файл

### Восстановление

1. Файл-ключ расшифровывается паролем пользователя
2. Каждый индекс в анонимной таблице заменяется исходным значением
3. HMAC-отпечаток сверяется для обнаружения подмены

## Testing

```bash
python -m unittest discover -s anonymizer/tests -v
```

Тесты проверяют:
- Движок анонимизации (нормализация, индексы, roundtrip)

- Отсутствие сетевых импортов (офлайн-гарантия)
